# Screenshot Guidelines

## Recommended Format

Use:

```text
PNG
```

## Recommended Naming

Use lowercase names with hyphens:

```text
medical-image-screening.png
doctor-patient-records.png
admin-dashboard.png
```

Avoid:

```text
Screenshot (123).png
IMG_123.png
final-final-new.png
```

---

# Privacy Checklist

Before committing a screenshot, verify that it does not expose:

```text
real passwords
JWT tokens
OpenAI API keys
database credentials
private medical data
personal phone numbers
private addresses
private emails that should not be public
```

For public GitHub screenshots, use demo/test accounts and synthetic healthcare data wherever possible.
