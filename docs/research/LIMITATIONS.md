# AI / ML Limitations

## Symptom AI

Possible limitations:

- incorrect reasoning,
- incomplete user symptom input,
- provider errors,
- model/provider drift,
- lack of physical examination,
- missing medical records.

## MRI Model

Possible limitations:

- training dataset bias,
- domain shift,
- scanner/protocol differences,
- softmax overconfidence,
- limited four-class task,
- no clinical validation,
- Grad-CAM is not ground-truth localization.

## Safe Interpretation

Use:

```text
AI-assisted
possible class
screening result
model score
decision support
```

Never treat the result as a confirmed medical diagnosis.
